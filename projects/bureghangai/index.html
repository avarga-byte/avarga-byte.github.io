Bureghangai Soum Portal

A local e-government portal for Bureghangai soum, Bulgan Province — public news, official resolutions and tenders, citizen complaints, and a staff dashboard behind it.

↑ The rebuilt frontend running live above (news/tender/complaint lists come from the private production API, so they read empty here — the full page layout, sections, and navigation work).

Overview

Bureghangai is a soum (district) of Bulgan Province in Mongolia. This portal is its local-government website: a public site where residents read news and official documents, submit complaints, and access services, plus an admin dashboard the soum office uses to publish and manage all of it. Internally the project is named "hutag".

What it does

  • Public news and announcements feed for the soum, with banners and a business directory.
  • An official-documents section: ИТХ resolutions (Хурлын тогтоол), Governor's decrees (Засаг даргын захирамж), and tender invitations (Тендерийн урилга).
  • Citizen complaint / petition submission (Өргөдөл гомдол) with a responses view.
  • COVID-era information and travel-request pages from when it was first built.
  • An admin dashboard for staff to publish news, manage documents, and handle submissions.

Why it's interesting

It's a real local-government product for a rural soum — the kind of civic infrastructure that's common for cities but rarely built for smaller administrative units. It shares a lot of DNA with the Nalaikh news project but is a separate site for a separate place.
