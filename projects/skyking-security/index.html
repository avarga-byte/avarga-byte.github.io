SkyKing Security Patrol

A guard patrol management system: a mobile app for security guards to check in at their posts, and an admin panel for the security company to oversee guards, sites, and incidents.

Guard mobile app — interactive

↑ A working React + Tailwind replica — open a post, tap "confirm location & check in" to see the GPS-verified check-in, and switch to the alerts tab.

Admin panel — interactive

↑ A working replica of the dispatch dashboard — live post map, guards roster, shift board, and alerts.

Overview

Built for a security services company, this system replaces paper patrol logs with a mobile check-in flow and a live admin view of every guard post.

What it does

  • Guards sign in to a dedicated mobile screen showing their assigned posts.
  • Checking in at a post requires confirming location on a map, so a check-in can't be faked from off-site.
  • Shift handovers between guards are tracked in-app.
  • The admin panel manages guards, guard posts, shift turns, customer sites, and alerts, with a full production dataset behind it (guards, posts, shifts, and customer records).
  • An invoicing companion tool (see Nehemj) generates the contracts and invoices for the security company's clients.

Why it's interesting

The GPS-verified check-in is the detail that makes this a real operations tool rather than a todo-list app — it directly addresses the thing paper patrol logs can't prove: that the guard was actually at the post.
