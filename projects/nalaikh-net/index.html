Overview

NalaikhNet is a local news and community app for Nalaikh, a district of Ulaanbaatar — a mobile app for residents plus an admin panel for staff, sharing one Node/Express + MongoDB backend. Residents read district news and browse classifieds; staff publish posts and manage the platform from the dashboard.

What it does

  • Resident mobile app — an Expo/React Native app with a district news feed, a classifieds/ads section (post and browse listings), a "free time" library of reading recommendations, and a resident profile, all behind a bottom tab bar.
  • Admin panel — staff sign in to publish and manage news posts, moderate users, maintain a company/organization directory, run promotional banners, and watch engagement statistics.
  • Shared backend — one API and data model behind both surfaces, with JWT auth and image uploads via Cloudinary.

Why it's interesting

It's a two-surface product — a resident-facing mobile app and a staff admin panel — built around a single backend, matching how a district information office actually publishes and moderates local news.

Tech Stack

React Redux React Native / Expo Node/Express MongoDB / Mongoose JWT auth Cloudinary
