Web App

UB Aerial

A production-ready marketplace for purchasing high-resolution drone survey imagery of Ulaanbaatar, Mongolia.

Overview

Users search the map, draw a selection polygon over the area they need, preview pricing, pay with Stripe, and download processed GeoTIFF/PNG/JPG exports of drone survey imagery. This is the most architecturally ambitious project in the portfolio — a real asynchronous processing pipeline, not just a CRUD app.

How it works

  • The React + OpenLayers frontend lets a user draw an area of interest on a map and get a live price quote before paying.
  • A Fastify API handles auth (JWT) and payments (Stripe), and writes the order into PostgreSQL with PostGIS for the spatial data.
  • Orders are queued in Redis via BullMQ rather than processed inline, so large exports don't block the API.
  • A Node.js worker picks up queued jobs and hands raster processing to a Python worker running GDAL, which clips and reprojects the requested imagery.
  • Finished exports are pushed to DigitalOcean Spaces and served to the user through a Cloudflare CDN.
  • The whole stack — frontend, API, workers, Postgres, Redis, and an nginx reverse proxy — is defined in Docker Compose, with a separate production compose file.

Why it's interesting

It's a genuine job-queue architecture: web request → queue → background worker → specialized processing (GDAL) → CDN delivery, with real payment handling and geospatial data (PostGIS) rather than a flat database. It also ships with a written DJI upload guide for the operational side of getting drone captures into the pipeline.

Tech Stack

React OpenLayers Fastify PostgreSQL + PostGIS Redis / BullMQ Python + GDAL Stripe Docker Compose DigitalOcean Spaces Cloudflare CDN
